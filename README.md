# Chirantan Chakraborty — Deep Tech Portfolio

A responsive, static portfolio built with plain HTML, CSS and JavaScript. Designed for GitHub Pages.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy to GitHub Pages
1. Create a GitHub repository named **`YOUR-USERNAME.github.io`** for a user site, or any repository for a project site.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment. Your site will be available at `https://YOUR-USERNAME.github.io/` (or `https://YOUR-USERNAME.github.io/REPOSITORY/` for a project site).

## Navigation
The portfolio has seven paginated sections. Use the sidebar, Previous/Next controls, or left/right arrow keys. The current section is reflected in the URL hash.

## Files
- `index.html` — content and page structure
- `style.css` — responsive dark-blue visual design
- `script.js` — pagination, navigation and subtle neural-network canvas
